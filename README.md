# 전자 서명 패드 (투명 배경 PNG 서명 생성기)

태블릿(iPad, Galaxy Tab 등)과 PC에서 터치펜(애플 펜슬, S펜), 손가락, 마우스로 서명하고 **서명의 실제 크기를 스마트하게 자동 감지하여 투명 배경 PNG 파일**로 즉시 저장할 수 있는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **서명 크기 스마트 자동 감지 (Auto-Crop)**
   - 서명 획이 그려진 최소/최대 좌표를 실시간으로 스캔하여, 불필요한 투명 여백 없이 **실제 서명 크기에 딱 맞춰진 크기(예: `280 × 95 px`)**로 자동 잘라내어 저장합니다.
   - 서명란 하단 상태 바에서 현재 서명의 가로&times;세로 크기가 실시간으로 표시됩니다.
2. **저장 크기 방식 선택 제공**
   - ✂️ **서명 크기 자동 맞춤 (추천):** 서명 부분만 깔끔하게 감지하여 여백 없이 저장 (문서 삽입 시 크기 조절이 매우 편리)
   - 📐 **서명란 전체 (500 &times; 200 px):** 규격 고정 크기 전체를 그대로 저장
3. **배경 투명 PNG 자동 생성**
   - 전자 결재, 계약서, 공문서 등에 바로 활용할 수 있도록 서명 획 이외의 영역은 100% 완전 투명(Alpha 0)으로 저장됩니다.
4. **태블릿 & 터치펜 최적화 (Pointer Events & 필압 감지)**
   - Apple Pencil, S-Pen 등 스타일러스 펜의 필압(Pressure) 감지 지원 (자연스러운 붓글씨/만년필 굵기 연출)
   - 화면 스크롤/제스처 간섭 방지 (`touch-action: none`)
   - 2차 베지어 곡선(Quadratic Curve) 기반 선 스무딩 알고리즘 적용
5. **편의 기능**
   - **되돌리기 (Undo):** 획 단위 실행 취소 (`Ctrl+Z` 단축키 지원)
   - **다시 서명 (Clear):** 원클릭 서명란 초기화
   - **펜 색상 및 굵기 조절:** 검정, 남색(결재용), 파랑, 붉은색(도장용) / 얇게, 보통, 두껍게
   - **가이드라인 & 격자 배경 토글:** 반듯한 작성을 위한 기준선 및 투명도 체감용 체커보드 패턴 제공
   - **투명도 및 크기 검증 미리보기:** [파일만들기] 클릭 시 생성된 PNG 파일의 실제 픽셀 규격과 투명도를 즉시 확인 가능

## 🚀 사용 방법

### 방법 1. 웹 브라우저로 바로 실행 (가장 간단)
- `index.html` 파일을 더블 클릭하거나 `start.bat`을 실행하여 즉시 사용합니다.

### 방법 2. 같은 Wi-Fi 내 태블릿에서 열기 (로컬 웹서버 실행)
`start.bat` 실행 후 `2`번을 선택하거나 터미널에서 다음 명령을 실행합니다:
```bash
python -m http.server 8080
```
태블릿 브라우저에서 `http://[PC_IP주소]:8080` 접속
