# 서명파일 제작기 (v1.0)

태블릿(iPad, Galaxy Tab 등)과 PC에서 서명 후 **서명 크기에 딱 맞춰 자동 크롭된 투명 PNG**를 **카톡공유**하거나 파일로 **저장**할 수 있는 미니멀 전자 서명 도구입니다.

---

## 🌟 주요 기능

1. **무조건 서명 크기에 맞춰 자동 크롭 (Auto-Crop)**
   - 불필요한 전체 여백 없이, 실제 서명 획이 그려진 영역만 딱 맞게(최소 패딩 포함) 자동으로 잘라낸 투명 PNG를 생성합니다.
2. **미니멀 아이콘 + 하단 텍스트 UI**
   - 💾 **저장:** 탭하면 크롭된 투명 PNG 파일을 기기에 바로 저장합니다.
   - 💬 **카톡공유:** 탭하면 카카오톡(나에게 보내기, 대화방), 메시지, AirDrop 등으로 서명 파일을 즉시 전송합니다.
   - ↩️ **되돌리기:** 마지막 획 실행 취소
   - 🗑️ **지우기:** 서명란 전체 초기화
3. **상단 1줄 통합 툴바**
   - 펜 색상 4가지 (검정, 남색, 파랑, 빨강)
   - 직관적인 펜 굵기 스트로크 바 (얇은 선, 보통 선, 굵은 선의 실제 두께 표시)
   - 투명 격자 배경 및 기준선 토글
4. **태블릿 & 터치펜 최적화**
   - Apple Pencil, S-Pen 등 스타일러스 펜의 필압(Pressure) 감지 지원 (붓글씨/만년필 필기감)
   - 터치 스크롤 및 제스처 방지 (`touch-action: none`)
   - 2차 베지어 곡선 기반 선 스무딩

---

## 🚀 사용 방법

### 방법 1. 브라우저에서 바로 열기
- `index.html` 파일을 더블 클릭하거나 `start.bat`을 실행하여 즉시 사용할 수 있습니다.

### 방법 2. 같은 Wi-Fi 내 태블릿에서 열기 (로컬 웹서버)
`start.bat` 실행 후 `2`번을 선택하거나 터미널에서 다음 명령을 실행합니다:
```bash
python -m http.server 8080
```
태블릿 브라우저에서 `http://[PC_IP주소]:8080` 접속
