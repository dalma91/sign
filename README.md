# 전자 서명 패드 (투명 배경 PNG 크롭 생성기)

태블릿(iPad, Galaxy Tab 등)과 PC에서 서명 후 **서명 크기에 딱 맞춰 자동 크롭된 투명 PNG**를 **카카오톡 아이콘으로 바로 전송하거나 저장 아이콘으로 다운로드**할 수 있는 미니멀 전자 서명 도구입니다.

---

## 🌟 주요 기능

1. **무조건 서명 크기에 맞춰 자동 크롭 (Auto-Crop)**
   - 불필요한 전체 여백 없이, 실제 서명 획이 그려진 영역만 딱 맞게(최소 패딩 포함) 자동으로 잘라낸 투명 PNG를 생성합니다.
2. **미니멀 아이콘 기반 UI**
   - 크고 둔탁한 텍스트 버튼 대신 깔끔한 **아이콘 버튼(Icon-First)** 디자인을 적용했습니다.
   - 💬 **카카오톡 아이콘 버튼:** 탭하면 카카오톡(나에게 보내기, 대화방), 메시지, AirDrop 등으로 서명 파일을 즉시 전송합니다.
   - 💾 **저장 아이콘 버튼:** 탭하면 크롭된 투명 PNG 파일을 기기에 바로 저장합니다.
   - ↩️ **실행취소 아이콘 (Undo):** 획 단위 취소
   - 🗑️ **지우기 아이콘 (Clear):** 서명란 전체 초기화
3. **태블릿 & 터치펜 최적화**
   - Apple Pencil, S-Pen 등 스타일러스 펜의 필압(Pressure) 감지 지원 (붓글씨/만년필 필기감)
   - 터치 스크롤 및 제스처 방지 (`touch-action: none`)
   - 2차 베지어 곡선 기반 선 스무딩
4. **상단 컴팩트 툴바**
   - 펜 색상 (검정, 남색, 파랑, 빨강)
   - 펜 굵기 (도트 크기 3단계)
   - 투명 격자 배경 및 기준선 토글

---

## 🚀 사용 방법

### 방법 1. 브라우저에서 바로 열기
- `index.html` 파일을 더블 클릭하거나 `start.bat`을 실행하여 즉시 사용할 수 있습니다.

### 방법 2. 같은 Wi-Fi 내 태블릿에서 열기 (로컬 웹서버)
`start.bat` 실행 후 `2`번을 선택하거나 터미널에서 다음 명령을 실행합니다:
```bash
python -m http.server 8080
```
태블릿 브라우저에서 `http://[PC_IP주소]:8080` 접속

## 📂 파일 구조

```
sign/
├── index.html        # 미니멀 웹 마크업 (카톡 아이콘 & 저장 아이콘)
├── style.css         # 모던 슬림 UI 스타일
├── script.js         # 자동 크롭, 카카오톡 공유, 파일 저장 로직
├── start.bat         # 원클릭 실행 배치 파일
└── README.md         # 프로젝트 안내서
```
