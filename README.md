# 전자 서명 패드 (투명 배경 PNG 서명 생성기)

태블릿(iPad, Galaxy Tab 등)과 PC에서 터치펜(애플 펜슬, S펜), 손가락, 마우스로 서명하고 **가로 500px &times; 세로 200px 크기의 투명 배경 PNG 파일**로 즉시 저장할 수 있는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **규격화된 500 &times; 200 px 서명란**
   - 최종 내보내기 시 정확히 `500 × 200 px` 크기의 PNG 파일로 생성됩니다.
2. **배경 투명 PNG 자동 생성**
   - 문서 삽입, 결재란, 전자계약서 등에 바로 사용할 수 있도록 서명 획을 제외한 배경은 100% 완전 투명(Alpha 0)으로 저장됩니다.
3. **태블릿 & 터치펜 최적화 (Pointer Events & 필압 감지)**
   - Apple Pencil, S-Pen 등 스타일러스 펜의 필압(Pressure) 감지 지원 (만년필/붓펜 같은 자연스러운 굵기 연출)
   - 화면 스크롤/제스처 간섭 방지 (`touch-action: none`)
   - 2차 베지어 곡선(Quadratic Curve) 기반 선 스무딩 알고리즘 적용 (계단 현상 및 각짐 방지)
4. **편의 기능**
   - **되돌리기 (Undo):** 획 단위 실행 취소 (`Ctrl+Z` 단축키 지원)
   - **다시 서명 (Clear):** 원클릭 서명란 초기화
   - **펜 색상 및 굵기 조절:** 검정, 남색(결재용), 파랑, 붉은색(도장용) / 얇게, 보통, 두껍게
   - **가이드라인 & 격자 배경 토글:** 반듯하게 서명할 수 있는 기준선 및 투명도 체감용 체커보드 배경 제공
   - **투명도 검증 미리보기:** [파일만들기] 버튼 클릭 시 생성된 투명 PNG를 체커보드 위에서 즉시 확인 가능

---

## 🚀 사용 방법

### 방법 1. 웹 브라우저로 바로 실행 (가장 간단)
- `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등의 브라우저에서 바로 열 수 있습니다. (별도 설치 불필요)

### 방법 2. 같은 Wi-Fi 내 태블릿에서 열기 (로컬 웹서버 실행)
PC와 태블릿이 같은 Wi-Fi에 연결되어 있다면 다음 중 하나로 서버를 띄워 태블릿 브라우저로 접속할 수 있습니다.

#### Python이 있는 경우:
```bash
python -m http.server 8080
```
태블릿 브라우저에서 `http://[PC_IP주소]:8080` 접속

#### Node.js가 있는 경우:
```bash
npx serve .
```
